# Sub-fetta 1.5.B — Config master TOML + parser nuovi formati (.xls, .doc, .rtf)

## Problem

Post-1.5.A i 7 profili dichiarano `provider: eurouter` esplicito. Denis vuole editare un solo file per cambiare comportamento globale (API key, modello, ecc.) senza toccare 7 profili. In più, i suoi materiali reali di test usano formati Office legacy (`.xls`/`.doc`/`.rtf`) non supportati da Sprint 1.

## Solution

Pattern master-profile inheritance + 3 parser binari custom.

**Master config**:
- Nuovo package `internal/config/` con `Master` struct + `Load(path)` + `Merge(master, profile) → profile merged`
- `labnexus.config.toml` al root con defaults globali (provider/modello/parametri/eurouter_api_key/ollama_endpoint)
- I 7 profili rinominati `.yml → .toml` e snelliti (campi opzionali, ereditati dal master)
- Runner: nuovo stage `loadMasterOptional` + `applyMasterToEnv` (propaga API key/endpoint via env vars, precedenza env > master)
- Validate sul profilo MERGED, non isolato (così profile parziale + master → valido)
- Flag `--config` CLI con fallback CWD

**Parser binari**:
- `.xls` via `github.com/extrame/xls` + `recover()` per-row (lib mature ma panic-prone su indici inconsistenti)
- `.doc` via `github.com/richardlehane/mscfb` (container OLE) + parser custom euristico ASCII + UTF-16LE
- `.rtf` parser custom ~150 LoC tokenizer (no lib esterna, principio "sottrarre è moltiplicare")

**Indirezione trigger**:
- `trigger_prompt_file` XOR `trigger_prompt` inline (FR-16)
- Path-safety: doppia check (lexical `..`/absolute in `validateTrigger` + runtime `EvalSymlinks` in `ParseTriggerPromptFile`)

## What Worked

- **Pattern recover-per-row su `extrame/xls`**: la lib panicava su file reale Denis (`M132.00_Rapporto Proficiency Testing.xls`) per row indici nil. `defer func() { _ = recover() }()` per ogni row + retry sul successivo → estrazione completa senza crash. Decision point step 4 risolto in ~15 min senza split fetta.
- **Master-profile inheritance**: schema chiaro (campo opzionale = zero-value → eredita), precedenza profile > master ovvia. 5 LoC totali per il Merge.
- **Skill `post-pivot-doc-audit-checklist`** (creata in 1.5.A compound) applicata pre-emptive a step 8 di implement: ha catturato `02-project.md` Layer 3 + USER-GUIDE + DEV-GUIDE riferimenti a `.yml` prima del review.
- **Review loop 2 fix-all Claude-only** efficace per ~75 min: 11/14 fix applicati, 3 deferred con rationale esplicito a idea backlog. Single-reviewer mode mistral 1/3 effective ha comunque catturato 4 HIGH validi (zero-value detection era invisible-to-Claude).
- **TOML come formato user-edited**: sintassi `key = value` esplicita più chiara a Denis (utente non-developer) vs YAML indentation. Lo schema TOML è auto-documentante.

## What Didn't Work

- **`EurouterAPIKey` + `OllamaEndpoint` del Master non propagati al runtime**: HIGH-config-2 spec gap FR-11. Il codice leggeva i campi nel TOML ma `provider.Select` continuava a leggere solo env vars. Denis che edita master e lancia → `EUROUTER_API_KEY non impostata`. Fix: `applyMasterToEnv` aggiunto in loop 2 review. **Lesson**: quando crei un campo TOML user-facing, verifica end-to-end che venga effettivamente USATO. Test integration mancante al implement step.
- **HIGH-config-1 (Merge zero-value detection) — bug subtle deferred**: `temperature == 0` non distingue "non setted" da "esplicitamente 0". Use case Denis (PT analysis deterministico) può inciampare. Fix vero richiede pointer types (refactor invasivo). Mistral l'ha catturato — io no. **Lesson**: i bug subtle di "Go zero-value semantics" emergono solo da reviewer esterno o test specifico, non da self-review.
- **Meta-prompt riga 284 invertita**: "NON suggerire eurouter, default ollama" — esattamente l'opposto post-pivot-3. Lo amendment 1.5.B nel docs non era abbastanza: doveva esserci anche audit di righe puntuali. **Lesson**: post-pivot-doc-audit-checklist applicato per file ma non per stringhe puntuali "default ollama" → estendere lo skill ad anche grep di pattern semantici, non solo sintattici (`.yml`).
- **Effective single-reviewer mode persistente**: 1.5.A loop 1 e 1.5.B loop 1 entrambi degraded (codex quota + ollama timeout). 5 giorni consecutivi senza external cross-verification quality/security/privacy. **Lesson sprint-level**: il preflight check va affidabile-zato (ollama pre-warmup automatic), o accetta degraded come modalità normale.

## Reusable Pattern

**Config master + profile inheritance pattern** (project skill nuova):
1. Master TOML al root con defaults globali
2. Profile TOML con campi obbligatori specifici + opzionali per override
3. `Merge(master, profile) → merged` con precedenza profile > master per campi setted
4. Validate post-merge (mai isolato)
5. CLI flag `--config` con fallback CWD per portabilità (binary può essere spostato lontano dal config)

**Recover-per-row guard pattern** (project skill nuova):
1. Lib esterna mature ma instabile su edge cases (es. `extrame/xls`)
2. Wrapper outer: `defer recover()` macro-level (intero file)
3. Wrapper inner: `defer recover()` per unità (row, sheet)
4. L'outer trasforma panic in error chiaro per il chiamante; l'inner skippa l'unità e continua

Entrambi sono candidate a framework promotion (pattern universal master-config + recover-per-unit).
