## Reusable Pattern

**Per-folder launcher con basename autoderive** — vedi `.pipeline/skills/project/per-folder-launcher-zero-cli.md` (creata in questo cycle). Pattern universale per CLI tool che hanno una nozione di "task" mappata a una cartella: 1 file `.command` (o `.bat`, o `.sh`) per cartella, identico across cartelle, il nome del job derivato da `basename` evitando hardcoding/template-variables. Zero-interaction UX per utenti non-technical.

**HTTP error body inclusion** — generalizzabile a qualsiasi HTTP client: quando `resp.StatusCode != 200`, `io.ReadAll(io.LimitReader(resp.Body, 4096))` + format error con `(status %d POST %s: %s)`. Trasforma "404" cieco in diagnostica completa.

**Verbose log per pipeline stage** — pattern generalizzabile a qualsiasi orchestratore: ogni step di pipeline emette (a) header "stage start", (b) sotto-info dettagliate (path, dim, parametri effettivi), (c) totale/aggregato, (d) "stage ok (Nms)". Costo: ~10 LoC per stage. Beneficio: diagnostica remota (es. smoke via WhatsApp) immediata.
